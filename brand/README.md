# NC Compliance logo

The mark is an oil drop (energy) with a tick (compliance).

| File | Use |
|---|---|
| `profile-picture.png` | Zoho/Gmail, WhatsApp Business, LinkedIn, X profile picture (dark, circle-safe) |
| `profile-picture-light.png` | Same, on white |
| `logo-horizontal-on-dark.png` | Logo with name, for dark backgrounds (transparent PNG) |
| `logo-horizontal-on-light.png` | Logo with name, for white backgrounds: documents, letterheads, invoices |
| `logo-mark.png` / `logo-mark.svg` | The drop on its own (transparent). SVG scales to any size for print |
| `logo-mark-white.svg` | White drop, for use on amber or photo backgrounds |
| `app-icon.png` / `app-icon.svg` | Square app icon (dark background) |
| `linkedin-banner.png` | LinkedIn company page cover (1584 × 396) |

Colours: amber `#E6A23C` (gradient `#F2B655` → `#D98E22`), ink `#14181D`, background `#0F1216`.
Fonts: Oswald 600 (name, upper case, wide letter spacing), IBM Plex Sans (text).

The website uses `public/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`,
`icon-192.png`, `icon-512.png`, `og-image.png` (link previews) and `email-logo.png` (email header).
